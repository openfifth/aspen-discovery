#### Aspen LiDA
- The Library Hours notice sent to LiDA is written by Aspen, so the times within it follow the new Time Format setting and the locale of the language the app requested. Event times and the library hours themselves are sent as raw values for the app to format, so they are unchanged. ([DIS-2604](https://aspen-discovery.atlassian.net/browse/DIS-2604)) (*CZ*)

#### Events
- Show the dates and times of Aspen native events using the format of the active language's locale, rather than always using the 12-hour format. This applies to event detail pages, event search results, the event calendar and event scrollers. ([DIS-2604](https://aspen-discovery.atlassian.net/browse/DIS-2604)) (*CZ*)
- Event scrollers for Communico, Springshare LibCal, Library Calendar, Assabet and LocalHop events share a display with Aspen native events, so the times in those scrollers follow the active language's locale as well. ([DIS-2604](https://aspen-discovery.atlassian.net/browse/DIS-2604)) (*CZ*)

#### Languages and Translations
- Languages > Locale now also determines the time format used to display hours in Aspen native events and in the Library Hours notice. Libraries using a language whose locale uses the 24-hour clock, such as British English, will see those times change from the 12-hour format, and can keep the 12-hour format by setting the new Time Format system variable. ([DIS-2604](https://aspen-discovery.atlassian.net/browse/DIS-2604)) (*CZ*)
